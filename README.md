# مِرسال — Mirsal ✉️

> **منصة استقطاب وإدارة العملاء من السوشيال ميديا — بدون حظر.**
> حوّل التعليقات والمتابعين إلى عملاء يدفعون: ردود تلقائية فورية، صندوق موحد لحظي،
> مراقبة الكلمات المفتاحية، حملات واتساب رسمية، وصفحات التقاط — كلها في منصة عربية واحدة.

---

## 💡 الفكرة والفلسفة

معظم أدوات "جلب العملاء" الرخيصة تعتمد على السحب الخفي للحسابات وتجاوز حماية المنصات —
وهو طريق يُصفّر فيه صاحب الحساب ويُقاضى قانونياً. **مِرسال** يبني النجاح على الطريق الرسمي:

| المبدأ | التطبيق |
|---|---|
| الواجهات الرسمية فقط | Meta Graph API + WhatsApp Business Platform (Cloud API) + TikTok Business API |
| العميل يتواصل أولاً | أتمتة «تعليق ← رسالة خاصة» ترد على من تفاعل معك — لا إزعاج ولا سبام |
| البيانات بموافقة صريحة | رقم العميل يدخل النظام لأنه أعطاه بنفسه (نموذج موافقة / محادثة) |
| محتوى عام فقط في المراقبة | مراقبة الكلمات المفتاحية في المنشورات والتعليقات العامة دون أي بيانات خاصة |

هذا يجعل المنصة **آمنة 100٪ من الحظر** ومتوافقة مع قانون حماية المعطيات الشخصية (18-07)
وGDPR — جاهزة للتوسع العالمي بلا مخاطر.

## ⚡ التشغيل

```bash
npm install
npm run dev        # http://localhost:3000
```

- الصفحة التسويقية: `/`
- لوحة التحكم: `/dashboard`
- صفحة التقاط تجريبية: `/p/salon-offer`

## 🧭 الصفحات

| الصفحة | ماذا تفعل |
|---|---|
| **لوحة التحكم** | إحصاءات لحظية، نمو العملاء، توزيع المنصات، تدفق النشاط الحي |
| **الصندوق الموحد** | كل محادثات إنستغرام/فيسبوك/واتساب/تيك توك في شاشة واحدة مع حالة القراءة ✓✓ |
| **العملاء (CRM)** | ملف كامل: المصدر، الرقم الموثّق، الوسوم، مؤشر الاهتمام، الحالة، الملاحظات |
| **الأتمتة** | «عندما يعلّق بكلمة سعر ← رد فوري في الخاص + جمع الرقم بموافقته» |
| **المراقبة اللحظية** | كلمات مفتاحية ← منشورات عامة تطلب منتجك ← زر «تحويل إلى عميل» |
| **الحملات** | قوالب واتساب معتمدة مع قمع إحصائي (أُرسلت ← وصلت ← قُرئت ← ردّوا) |
| **صفحات الالتقاط** | روابط تجمع اسم الزبون ورقمه بموافقته — تظهر في اللوحة لحظياً |
| **الإعدادات** | خطوات الربط الرسمي لكل منصة + عناوين Webhooks + سياسة الخصوصية |

## 🔌 الربط الحقيقي بالمنصات (جاهز في الكود)

الكود يتضمن Webhooks رسمية كاملة الهيكل:

```
POST/GET /api/webhooks/meta      # إنستغرام + فيسبوك (تحقق hub.challenge + معالجة التعليقات)
POST/GET /api/webhooks/whatsapp  # واتساب Cloud API (رسائل واردة + تحديثات الحالة)
```

للتفعيل الحقيقي:
1. أنشئ تطبيقاً في [Meta for Developers](https://developers.facebook.com) وأضف منتجات
   Instagram / WhatsApp.
2. ضع متغيرات البيئة:

```bash
META_VERIFY_TOKEN=كلمة-سر-التحقق
WHATSAPP_VERIFY_TOKEN=كلمة-سر-التحقق
WHATSAPP_TOKEN=توكن-الدائم        # لإرسال الرسائل فعلياً
WHATSAPP_PHONE_NUMBER_ID=...      # من إعدادات واتساب Cloud API
```

3. ضع عنواني Webhook أعلاه في إعدادات التطبيق، واشترك بالحقول: `messages`,
   `feed`, `comments`.

**ملاحظة:** المحاكاة اللحظية (الوضع الحي) تعمل فقط في البيئة التجريبية؛ عند الربط
الحقيقي تُستبدل ببيانات Webhooks الفعلية — بنية البيانات واحدة تماماً.

## 🏗️ البنية التقنية

- **Next.js 15 (App Router) + React 19 + TypeScript** — واجهة عربية RTL كاملة بخط Cairo
- **Tailwind CSS v4** — تصميم متجاوب داكن/فاتح
- **طبقة بيانات JSON بسيطة** (`data/db.json`) لبيئة العرض — تُستبدل بـ PostgreSQL + Drizzle/Prisma
  في الإنتاج دون تغيير واجهات API (كل القراءات/الكتابات تمر عبر `src/lib/store.ts`)
- **Polling كل 3-5 ثوانٍ** للتحديث اللحظي — يُرقّى إلى SSE/WebSocket في الإنتاج
- **بلا مصادقة بعد** — النسخة القادمة تضيف تسجيل الدخول ومساحات عمل متعددة

```
src/
  app/
    page.tsx                  # الصفحة التسويقية
    p/[slug]/                 # صفحات الالتقاط العامة
    dashboard/                # 8 صفحات اللوحة
    api/                      # 18 واجهة REST + Webhooks رسمية
  components/                 # مكتبة واجهة مشتركة (UI, Sidebar, Logo)
  lib/                        # البيانات، المحاكاة، الأدوات، الـhooks
```

شروط الخدمة — نحن نساعد الشركات على الردّ أسرع، لا على مضايقة الناس.
