# VITO BYTE FLOW RELAY — عقدة الأتمتة (الجلسة السحابية المعزولة)

عقدة واحدة صفرية التكلفة تشغّلها المالك على أي جهاز يملكه (حاسوبه الشخصي كافٍ) — المنصة (Workers) تبقى بلا GPU وبلا مفاتيح.

## التشغيل
```bash
NEXUS_ORIGIN=https://nexus.vitobytestudio.workers.dev \
VBS_RELAY_TOKEN=<نفس سر المنصة VBS_RELAY_TOKEN> \
DRIVER=flow \
PORT=8801 \
node node.mjs
```

## أسرار المنصة (GitHub Secrets → تُضبط بطلب من المالك)
- `VBS_RELAY_TOKEN` — التوكن المشترك بين المنصة والعقدة
- `VBS_SESSION_KEY` — 64 خانة hex: مفتاح تشفير جلسات الزبائن (AES-GCM)
- `VBS_RELAY_ORIGIN` — عنوان العقدة كما يراه الزبون (https — عبر نفق مثل cloudflared إن كانت على جهاز شخصي)

## السائقان
- `DRIVER=mock` — للبوابات والتجارب: ربط فوري وتوليد فوري (لا متصفح).
- `DRIVER=flow` — الإنتاج: Playwright Chromium يفتح دخول جوجل الرسمي (الزبون يسجل أو **يُنشئ حساباً** في النافذة نفسها)، الجلسة تعود للمنصة مشفرة، والتوليد ينفذ على حسابه ويُعيد رابط الفيديو لمشغل المنصة — صفر تخزين.
  ```bash
  npm i playwright && npx playwright install chromium
  ```

## الأمان
- كلمات السر لا تمر عبرنا إطلاقاً — الدخول على صفحة جوجل الرسمية نفسها.
- الجلسة مخزنة مشفرة AES-GCM في KV المنصة ومرتبطة بحساب الزبون، ولا تُفك إلا لحظة تنفيذ مهمته.
- `unlink` من الواجهة يمحو الجلسة نهائياً فوراً.
