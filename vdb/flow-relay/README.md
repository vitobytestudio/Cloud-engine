# VITO BYTE FLOW RELAY — عقدة الأتمتة التفاعلية (الجلسة السحابية المعزولة)

عقدة واحدة صفرية التبعيات تشغّلها المالك على أي جهاز يملكه (حاسوبه الشخصي كافٍ) — المنصة (Workers) تبقى بلا GPU وبلا مفاتيح.

## ماذا تفعل النافذة التفاعلية للزبون؟
1. الزبون يضغط «ربط حساب Google Flow بضغطة واحدة» في المنصة — تفتح نافذة **داخل منصتنا** تضم بثاً تفاعلياً حياً لصفحة **دخول جوجل الرسمية** (CDP `Page.startScreencast` فوق WebSocket صفر تبعيات) — يعمل على الهاتف (أبعاد 390×844 تلقائية من User-Agent) والحاسوب.
2. الزبون يكتب بريده وكلمة السر **بنفسه** ويؤكد التحقق بخطوتين **بيده وبرضاه الكامل** — 2FA والحظر الأمني لجوجل يُحلان بنفسه في نافذته. **لا نلمس كلمة السر في أي حقل لدينا** — ما يمر عبرنا بكسلات الصفحة وأحداث اللمس/الفأرة فقط.
3. المتصفح **غير مكشوف**: Patchright إن وُجد وإلا Playwright، مع إخفاء `AutomationControlled` وإزالة `--enable-automation` — تجنّب رسالة "This browser or app may not be secure".
4. عند وصول الجلسة إلى `labs.google` تُحفظ `storageState` مشفرة لدى المنصة، **يُغلق البث فوراً**، وتظهر «تم الربط بنجاح» — ثم يبدأ التوليد في الخلفية والنتيجة تعود للمنصة.

## التشغيل
```bash
NEXUS_ORIGIN=https://nexus.vitobytestudio.workers.dev \
VBS_RELAY_TOKEN=<نفس سر المنصة VBS_RELAY_TOKEN> \
DRIVER=flow \
PORT=8801 \
node node.mjs
```
- متصفح غير مكشوف (مرة واحدة): `npm i patchright && npx patchright install chromium` — أو `npm i playwright && npx playwright install chromium`.
- خادم بلا شاشة: شغّل داخل Xvfb (`xvfb-run node node.mjs`) أو أضف `HEADLESS=1` (للتوليد فقط — الدخول التفاعلي يفضل رأسه مرفوعاً دائماً لتجنّب حظر جوجل).
- مهلة الدخول الافتراضية 10 دقائق: `LOGIN_TIMEOUT_MIN=15` لتغييرها.
- عنوان النافذة للزبون يصبح `VBS_RELAY_ORIGIN` — على جهاز شخصي يكفي نفق https (مثل cloudflared) ليصبح `https://relay.nطيك`.

## أسرار المنصة (GitHub Secrets — تُنقل للعامل تلقائياً في كل نشر)
- `VBS_RELAY_TOKEN` — التوكن المشترك بين المنصة والعقدة
- `VBS_SESSION_KEY` — 64 خانة hex: تشفير AES-GCM لجلسات الزبائن
- `VBS_RELAY_ORIGIN` — عنوان العقدة كما يراه الزبون (https)

## السائقان
- `DRIVER=mock` — للبوابات والتجارب: ربط فوري + إطارات محاكاة حية عبر نفس جسر WS (تُختبر بـ `ws-gate.mjs` في كل نشر).
- `DRIVER=flow` — الإنتاج: الدخول التفاعلي الحقيقي + تنفيذ التوليد على حساب الزبون.

## الأمان
- كلمة السر لا تمر عبرنا ولا تُخزن ولا تُرى — حقول جوجل الرسمية داخل متصفح العقدة فقط.
- الجلسة (`storageState`) تُرسل للمنصة حيث تُشفَّر AES-GCM مرتبطة بحساب الزبون — العقدة لا تحفظ شيئاً على القرص.
- `unlink` من الواجهة يمحو الجلسة نهائياً فوراً؛ توكنات الربط تُحرق لحظة الاستخدام (TTL 15 دقيقة).
- القناة التفاعلية: توكن لمرة واحدة مفت المشاهدة — مُشاهد جديد يُقصي السابق؛ أحداث الإدخال مقيّدة ومقصوصة.

## بوابة الجسر
```bash
RELAY=http://127.0.0.1:8801 node ws-gate.mjs
```
تتحقق حياً: مصافحة WS + وصول الإطارات + بقاء القناة عند إدخال أحداث + اكتمال دورة الربط — تعمل في CI على mock.
