# مِرسال — النسخة الإنتاجية

منصة توصيل الزبائن الجاهزين للفريلانسر الجزائري — بنية سحابية حقيقية على Cloudflare.

## البنية

| المكوّن | الخدمة | الوظيفة |
|---|---|---|
| `src/index.ts` | Workers (Hono) | التطبيق الكامل + صيانة دورية (حذف >72س، إبطال الاشتراكات) |
| D1 `mirsal-db` | قاعدة بيانات SQL | المستخدمون، الجلسات (توكن مبعثر)، الاشتراكات، الطلبات، الزبائن، التدقيق |
| R2 `mirsal-receipts` | تخزين مشفّر | وصولات الدفع AES-256-GCM — النص الصريح لا يُكتب أبداً |
| KV | ذاكرة مؤقتة | حدود المعدل وأقفال المحاولات |
| `public/` | واجهة | تطبيق عربي RTL — بلا أطر عمل، جوال أولاً |

## الحماية (مضادة للاحتيال بالتصميم لا بالوعود)

1. **مرجع فريد لكل طلب** `MRS-XXXXXX` — يُكتب في وحدة التحويل إلزامياً.
2. **بصمة SHA-256 فريدة عالمياً** للوصل — نفس الملف لا يُقبل في طلبين أبداً (409 فوراً).
3. **تشفير AES-256-GCM** لكل وصل قبل تخزينه في R2.
4. **قرار بشري موثّق** — لا تفعيل آلي أبداً؛ كل اعتماد/رفض مُسبَّب ومسجَّل باسم صاحبه.
5. **رصد الأنماط** — نفس (اسم المحوّل + التاريخ) لمستخدمين مختلفين = علم مخاطرة على الطلب.
6. **PBKDF2-SHA256 ‏100 ألف تكرار** لكلمات السر؛ جلسات بتوكن مبعثر (SHA-256 في DB).
7. **CSRF مزدوج الإرسال** على كل غير GET + قفل بعد 8 محاولات (15 دقيقة) + حدود معدل لكل IP/مستخدم.
8. **سجل تدقيق غير قابل للتعديل** لكل فعل حساس.

## التشغيل محلياً

```bash
npm install
npx wrangler d1 migrations apply mirsal-db --local
npx wrangler dev          # http://localhost:8787
```

`.dev.vars` يُولَّد محلياً ولا يُرفع أبداً إلى git.

## النشر إلى Cloudflare (خطوة واحدة)

```bash
export CLOUDFLARE_API_TOKEN=...   # توكن بصلاحيات Workers + D1 + R2 + KV
./scripts/deploy.sh
```

السكربت ينشئ D1 وR2 وKV، يطبّق الترحيلات، يولّد الأسرار، وينشر.

### الأسرار الإنتاجية
- `RECEIPT_ENCRYPTION_KEY` — مفتاح تشفير الوصولات (64-hex). **مَن يملكه وحده يقدر يقرأ الوصولات — يُحفظ في مكان آمن خارج Cloudflare.**
- `INGEST_TOKEN` — رمز استقبال الزبائن من الموصلات الرسمية.
- `ADMIN_EMAIL` — بريد المدير؛ أي تسجيل بهذا البريد يحصل على دور الإدارة.

### استقبال الزبائن (قنوات رسمية فقط)
```
POST /api/ingest
X-Ingest-Token: <الرمز>
{
  "items": [{
    "title": "...", "excerpt": "...", "author_public": "...",
    "platform": "facebook|instagram|telegram|web",
    "source_url": "https://...",     // إلزامي وفريد
    "keyword": "...", "location_hint": "...",
    "published_at": 1730000000000    // الجديد فقط (<72 ساعة)
  }]
}
```
