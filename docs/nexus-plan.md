# NEXUS — وثيقة الخطة الحية

الحالة: **تخطيط ونقاش** — البناء لا يبدأ إلا بأمر المالك الصريح.
آخر تحديث: 2026-11-05 (نوفمبر 2026)

---

## 1. التعريف

NEXUS منصة جزائرية **2 في 1** للتجار الإلكترونيين:
1. **متجر إلكتروني خاص** برابط مستقل سريع (يوجَّه إليه زبائن الإعلانات بلا تشتيت).
2. **سوق عام وفيد استكشاف** — منتجات التاجر تظهر تلقائياً لزبائن جدد عبر حركة الزوار المشتركة.

مرجع المنتج = منشور المالك (الحلقتان السابقتان أُرشفتا ومُحيت أنظمتهما من الإنتاج نهائياً — PRs #105–#113).

## 2. التمركز التنافسي (محسوم)

| المستوى | المضمون | موقفنا |
|---|---|---|
| أساسيات البقاء | متجر سريع، استمارة COD كاملة (كل الولايات والبلديات)، بيكسل فيسبوك/تيك توك، كوبونات، سرعة على 3G، تحصيل بريدي موب | شرط دخول — بمستوى RYADOO لا أقل |
| خارج نطاقنا | ربط APIs شركات التوصيل (30+ لدى RYADOO) | **خارج النطاق بأمر المالك** — الشحن مسؤولية شركة التوصيل |
| أسلحتنا الفاصلة | — | السوق/الفيد (هم يبيعون محلاً معزولاً؛ نحن محل داخل مول)، الوكيل الذكي متعدد القنوات بالدارجة (صفر ذكاء عند المنافسين)، الأستوديو البشري، السمعة والشارات، إعلانات الفيد |

منافسون مرجعيون: RYADOO (700 دج، 69 ولاية، 30+ توصيل، تجربة يومين) — Tassyir (1900/4900/9900 دج) — YouCan ($29+ بالدولار + عمولة COD) — Shopify (غير عملي جزائرياً).
ميزة موتورنا: فوترة بالدينار المحلي بينما الأجنبية فاتورة دولية + عمولات.

## 3. الوكيل الذكي (محسوم)

- **وحدة العدّ = الجلسة** (استفسار زبون واحد حتى إغلاقه: طلب مؤكد أو تسليم يدوي للتاجر أو صمت 24 ساعة). الرسائل حرّة داخل الجلسة.
- **حارس داخلي** غير معلن: ~12 تبادلاً كحد داخل الجلسة ثم تسليم أنيق للتاجر.
- **القنوات** (رسمية حصراً، تدرّجاً): داخل متجر NEXUS أولاً → ماسنجر (Messenger Platform + App Review) → إنستغرام دايركت → واتساب Cloud API (كلفة Meta لكل محادثة تُحسب حينها).
- **الشفافية**: الوكيل يعلن عن نفسه في أول كل محادثة (سياسات Meta + ميزة ثقة).

## 4. معمارية الذكاء الاصطناعي — السلسلة التسلسلية (قرار المالك المحسوم)

**المبدأ المحسوم (صياغة المالك)**: داخل المزود الواحد يُملأ النموذج حتى نضوب حصته كاملة ثم الانتقال مباشرة للنموذج الموالي من المتبقي، وعند نفاد المزود بأكمله الانتقال للمزود الموالي. مؤشر «النموذج النشط» متغير واحد يُدار بسهولة.

**ترتيب السلسلة** (الأوسع والأرخص أولاً، الأندر والأذكى آخراً):
`Gemma 3 → 2.0 Flash-Lite → 2.0 Flash → 2.5 Flash (احتياط ثمين لا يُمس إلا نضوباً لما قبله) → نماذج Groq الأسرع تلو الأخرى → Workers AI → OpenRouter`

**صمام الضغط (الاستثناء الوحيد)**: في ذروة الازدحام إذا تشبع النموذج النشط بسقفه الدقيق، يسكب الموجّه الفائض اللحظياً على نماذج ذات رصيد، ويعود للنموذج النشط الواحد بانقشاع الذروة.

### الدلاء الموثقة بعد الجرد الشامل الرسمي (التفصيل الكامل في docs/ai-fleet.md)
| المزود | الجدار الحاكم | الواقع اليومي |
|---|---|---|
| Gemini — كل نماذجه كلٌّ بدلو مستقل (gemma 3، flash-lite، flash، جيل 3.x/4) | gemma: TPM 15K (~3,500–5,000 نداء)؛ flash-lite/flash: RPD 1,500+1,500؛ الجيل الحالي يُقاس عند البناء | ~7,000–9,500 نداء — القاطرة |
| Groq — كل نموذج بدلو مستقل لكن جدار TPD 200 ألف رمز/نموذج | gpt-oss-120b + gpt-oss-20b + qwen3.8-27b | ~170–200 نداء — طبقة السرعة + prompt-guard مجاني (14,400/يوم) لفلترة المدخلات |
| Workers AI | 10,000 نيورون/يوم للحساب كله (التناوب يُنوّع الجودة لا يضاعف الكمية) | ~12–15 حديثاً ثقيلاً أو 100+ خفيفاً |
| OpenRouter | 50 طلب/يوم للحساب (نستعمل `openrouter/free` الموجّه التلقائي) | طوارئ أخير |

### قواعد الموجّه
1. **السياق المقتصد**: أوراق منتجات مختصرة + آخر رسالتين (~2,800 رمز للنداء) — يضاعف السعة.
2. **التصاق الجلسة**: المحادثة تبقى على النموذج النشط؛ التنقل عند حدود الجلسات أو الاضطرار.
3. **دفتر صحة لحظي**: عدادات يومية ورمزية لكل نموذج + تبريد عند 429 وتخطيه فوراً حتى التجديد.
4. **دفتر استهلاك**: كل نداء يُسجَّل (نموذج/رموز/كمون) — دليل التسعير وعتبة الترقية.
5. **عدالة المجدول**: تدوير بين التجار — لا يبتلع تاجرٌ الأسطول.
6. **قائمة النماذج في إعداد واحد** — تبديل نموذج متقاعد = سطر واحد. الأرقام الدقيقة لكل نموذج تُتحقق عند البناء.
7. **لا جلسة تُفتح والسلسلة شبه فارغة**: الوكيل يستقبل رقم الزبون ويسلّمه للتاجر بأناقة.

### السعة والعتبة (مصححة بالجرد الشامل)
- السعة: ~7,200–9,700 نداء/يوم ≈ **1,200–1,700 جلسة/يوم** واقعياً، و**~2,000** بالسياق المقتصد.
- تغطي: الإطلاق الناعم (50–150 تاجراً نشطاً) براحة؛ تتضيق عند بيع حصص Pro/VIP الكاملة.
- **عتبة الترقية**: استغلال مجاني >80% ثلاثة أيام متتالية، أو أول اشتراك Pro/VIP حقيقي → تفعيل فوترة الاستهلاك (Gemini Tier 1: 2,000 RPM بلا سقف يومي، ≈ 0.75 دج للجلسة) — **بأمر المالك حينها**.

## 5. الباقات (المنشور المرجعي — الأسعار مؤجلة للتحليل الدقيق)

هيكل المجمد: Free / Pro (شارة توثيق + وكيل جدولة) / VIP (صدارة السوق + فيديو بريميوم برعاية Vito Byte Studio). «استقبال الطلبيات واستمارات الشحن غير محدود بكل الباقات». المنتج الإضافي بدينار. إعلانات الفيد: فيديو من التاجر أو ممنتج عبر الأستوديو بأولوية.
الشعار: «أي تاجر ينضم لمنصة NEXUS هو شريك وعضو فعال في المجتمع بقيمته وسمعته» — يتحول لنظام سمعة حقيقي (تقييمات زبائن، سرعة رد).
الأستوديو: خدمة بشرية من فريق المالك بمقاعد أسبوعية محدودة (نظام حجز وقائمة انتظار) — الندرة جزء من التسعير.

## 6. مراحل البناء (بعد إذن المالك)

- **م1 — النواة**: حسابات، متجر سريع برابط مستقل، منتجات، استمارة طلبية كاملة (كل الولايات والبلديات)، صندوق طلبيات، لوحة أرباح/مصاريف، فيد/سوق/استكشاف. بلا دفع ولا وكيل.
- **م2 — الوكيل والباقات**: جدول التناوب، الجلسات، قناة داخل المنصة ثم ماسنجر، فرض الباقات والشارات، الدفع الديناري عبر بوابة بريدي موب الآلية حصراً (لا Chargily ولا SofizPay) بأمر المالك.
- **م3 — الأستوديو والإعلانات**: كتالوج مقاعد الأستوديو، إعلانات الفيد بموافقة تحريرية.

معايير المصنع تسري حرفياً: هارنس بوابة قبل التسليم، tsc نظيف، minify دائم، عزل تام عن بقية المشاريع، قفل إدارة سري (رابط خفي + 401 صامت + k0+pbkdf2)، المفاتيح أسرار GitHub/Cloudflare لا في الكود، PR→merge نشر تلقائي.

## 7. أسئلة مفتوحة (بانتظار الحسم)

2. هل تدخل البيكسل والكوبونات النواة الأولى أم تُؤجل؟
3. اسم النطاق النهائي وهوية العلامة.
