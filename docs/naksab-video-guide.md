# NAKSAB — دليل تصميم الفيديوهات التسويقية (v1)

القاعدة الأم: **الفيديو منصّة مصغّرة**. من يراه بعد 10 ثوانٍ يجب أن يعرف ثلاثة أشياء بلا شرح: ما هذه المنصة، أين مكانه منها، وماذا يفعل الآن (CTA). نفس منطق «البابين» في الهيرو: المشاهد يختار بابه بنفسه.

---

## 1) الهوية البصرية — النظام المشتق من المنصة

| العنصر | القيمة | الاستخدام |
|---|---|---|
| الخلفية | كحلي شديد الدكانة `#05060a` | خلفية كل مشهد ومونتاج |
| الأساسي | بنفسجي `#7c6cff` | العناوين، الخطوط المتحركة |
| الثانوي | سماوي `#00d4ff` | التمييز، الأزرار، المؤشر |
| لمسة | وردي `#ff6cb5` | بالكاد — لإبراز لحظة النجاح (اكتمال مشروع) |
| الخط العربي | IBM Plex Sans Arabic — أوزان 600/700 | كل نص الشاشة العربي |
| الخط اللاتيني | Space Grotesk للعنوان + Inter للنص | كلمة NAKSAB والأرقام |
| العناصر | خطوط شبكية خفيفة + كرات ضوئية (orbs) تتوز ببطء | خلفية كل مشهد نصي |
| الحركة | ظهور ناعم لأعلى (translateY + fade)، لا دوارات ولا ارتدادات | إيقاع راقٍ يشبه الموقع |

قاعدة النظافة: كل نص شاشة على شريط شبه شفاف داكن `rgba(12,14,23,.6)` بحدود شعرية بيضاء 8% — نفس بطاقات الواجهة. لا ظلال قوية، لا ملامح صاخبة.

## 2) المادة الأهم: سجّل المنصة نفسها

الناس يثقون بما يرون يعمل. سجل الشاشة أثمن من أي تصميم:
- متصفح كروم بحجم نافذة **1440×900**، تكبير الصفحة 110%، الثيم داكن.
- **أمام الكاميرا لا شيء إلا المنصة** — لا شريط مهام، لا إشعارات، لا تبويبات أخرى.
- جهّز بيانات عرض حقيقية: حساب عميل + حساب VITO BYTE STUDIO كمستقل (نصيحة الجولة السابقة)، فتحصل على لقطات ممتلئة: طلب حي، عروض واردة، غرفة مشروع برسائل ومراحل، تقييم بنجوم.
- لقطات الهدف بترتيبها: كتابة طلب (8ث) → وصول العروض مرتبة (6ث) → قبول وفتح غرفة (6ث) → مرحلة مسلَّمة وتأكيد (6ث) → تقييم 5 نجوم (4ث).

## 3) البنية السردية الموحدة (لأي فيديو)

| اللحظة | المدة | المحتوى |
|---|---|---|
| الهوك | 0–3 ث | سؤال يلمس ألم المشاهد — نص كبير يُقرأ بلا صوت |
| المشكلة | 3–8 ث | الوضع الحالي: البحث المتناثر في فيسبوك، لا ضمان، لا وضوح |
| الحل | 8–16 ث | NAKSAB بالاسم + لقطات شاشة حية |
| الدليل | 16–24 ث | غرفة مشروع وتأكيد متبادل — نقطة التفرد |
| CTA | 24–30 ث | «مجاني أثناء الإطلاق — كل شيء بالدينار» + الرابط |

قواعد ثابتة:
- الموسيقى: إلكترونية هادئة إيقاعها 90–110 BPM بمستوى منخفض لا يدفن التعليق.
- الترجمة النصية دائماً (أغلب مشاهدات فيسبوك صامتة).
- شعار VITO BYTE STUDIO خاتمةً 2 ثوانٍ بعد CTA — لا في الافتتاح.
- **ممنوع**: لقطات ستوك درامية، أسعار PRO، وعد أرباح، شعارات شركات حقيقية، عبارات «الأول في الجزائر» المطلقة.

## 7) سلسلة المحتوى بعد الإطلاق (إيقاع أسبوعي)

1. «مشروع من الطلب إلى التقييم» — قصة حقيقية من المنصة (60ث يوتيوب + قصاصة 30ث).
2. «موهبة الأسبوع» — ملف مستقل ولماذا يستأجَر (تصوير ملفه + صوتك).
3. «نصيحة في 30 ثانية» — كيف تكتب طلب يجيب عروضاً جيدة (تعليمي يبني ثقة).
4. عدّاد قبل فتح PRO لاحقاً — يُصنع يوم قرارك، لا الآن.

## 8) فيديوهات داخل المنصة (معرض أعمال المستقلين) — القواعد القائمة

المنصة تقبل روابط يوتيوب/فيميو فقط ولا تستضيف فيديو (قرار معماري ثابت: لا تكاليف تخزين ولا محتوى خامل). انصح المستقلين في دليل البداية بمعايير: بداية هادئة في أول 3 ثوانٍ، 16:9 أو 9:16 نظيف، عرض العمل لا الوجه، مدة أقل من دقيقتين، وعنوان واضح. هذا يرفع جودة المعرض بلا أي كود.

## 9) خطة الإنتاج العملية (يومان)

- اليوم 1: تجهيز حسابي العرض (عميل + VITO BYTE STUDIO ببيانات حقيقية) + تسجيل 12 لقطة حية حسب قائمة القسم 2.
- اليوم 2: مونتاج CapCut بالماستر 16:9 (سكريبت 1) ثم إعادة تأطير 9:16 و4:5 + النسخة الثانية للمستقلين + 3 صور حالات واتساب من إطارات الفيديو.
- الصوت: صوتك أنت الأصدأ والأصدق للجمهور الجزائري — أو أجهّز لك تعليقاً صوتياً بالفصحى البسيطة بأداة الصوت لديّ إن فضّلت، بكلمتك فقط.
