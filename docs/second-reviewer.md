# المراجع العقلي الثاني — بوابة مراجعة مستقلة عن كاتب الكود

## الفكرة
نقد حقيقي للبنية الحالية: كاتب الكود والمراجع الآلي (الأنواع + البوابات) كيان واحد. هذه البوابة تُدخل **عقلاً ثانياً مستقلاً** يراجع كل فرق قبل الدمج، بمعزل كامل عن نية الكاتب — ويملك حق الإسقاط.

## كيف تعمل
- خطوة CI جديدة في `nexus-deploy.yml` تعمل على **push وpull_request** معاً (فأصبحت بوابات البناء الحية حاجزة قبل الدمج فعلاً، لا بعد نشره).
- تجلب فرق الـPR (`origin/base...HEAD`) وترسله لمفتاح/مفاتيح مراجعة.
- **التفعيل بأمر المالك حصراً**: أضف سطراً إلى سر GitHub باسم `AI_KEYS`:
  - `reviewer=AIza...` (مراجع Gemini) أو `reviewer-groq=gsk_...` (مراجع Groq) أو عدة مفاتيح معاً.
- **كل مفتاح reviewer يجيب باستقلال**؛ حكم `BLOCK` من أي مراجع **يُسقط البناء** (خطأ في الـPR قبل الدمج).
- تعليمة المراجع: أمن أولاً (حقن/تصريح/CSRF/أسرار) ثم منطق وعقود وفقدان بيانات، ويُمنع الحجب لذوق الأسلوب.
- بلا مفتاح مراجع: البوابة تعلن أنها غير مفعّلة وتمر — لا انسداد زائف.

## لماذا مفاتيح المالك وليس مفتاحاً مدمجاً؟
نفس قاعدة الأسطول: المفاتيح أسرار GitHub حصراً (`AI_KEYS`)، والحدود والأسماء واختيار المزود قرار المالك. البنية تنتظر المفتاح — لا تنتظر قراراً.

## حفر المراجع (الرد على «هل اختبرتم الرفض فعلاً؟»)
- `npm run reviewer-drill` — مرحلتان:
  1. **حتمية بلا شبكة**: تختبر أنابيب التحليل نفسها التي تشغّل بوابة CI (مكتبة مشتركة `review-lib.mjs` — مصدر واحد للحقيقة). اصطادت فعلاً علة صيغة JSON وحيدةها في أول تشغيل وأُصلحت.
  2. **حية بمفتاح المالك**: فرق يحوي ثغرات مزروعة عمداً (مفتاح API مصمت + SQL بلسان + كلمة سر في سجل) — **أي مراجع يجيب غير BLOCK يُسقط الحفر**. تعمل كخطوة CI دائمة؛ وبدون مفتاح محلياً تتخطى المرحلة 2 معلنة.
- **وضع الإلزام**: متغير المستودع `REQUIRE_REVIEW=1` يجعل غياب المراجع أو صمتها فشلاً لا تجاوزاً (بيد المالك متى أراد تفعيل المراجعة الإلزامية).
- سير العمل يجيب السؤال الثاني ميكانيكياً: البوابات كلها على زناد `pull_request` — الدمج على أحمر مستحيل حتى مع بوابات بناء خضراء، والمراجع من يملك الإسقاط الوحيد الإضافي.

## ترقية البوابة البصرية (الرد على ملاحظات التباين والخطوط)
- **muted يُقاس على سطحه الفعلي**: على الخلفية 7.1:1 وعلى البطاقة 8.3:1 — كلاهما ≥ 4.5 (AA صارم).
- **dim على البطاقة كانت 2.9:1 فشل حقيقي أمسسته البوابة** → رُفع الرمز إلى `#666e8a` (3.4:1 على البطاقة).
- **الأرضية**: 11px قاع مطلق للملصقات الميتا فقط (شارات/تبويبات/وسوم)، و**كل نص قراءة ثانوي ≥ 12px** (أمسكت البوابة .hint/.price-old/.store-line ورفعتها)، وجسم سطح المكتب ≥ 13px بنظام الأنظمة.

## حدود صادقة تبقى
- المراجع الثاني يجيب بنص (LLM) — قد يخطئ في الاتجاهين؛ لذلك حجبه مسؤولية مفردة موثقة في سجل الـPR، والمالك يرى كل ملاحظاته.
- البوابة البصرية بنيوية محسوبة (تباين/لمس/حركات/أرضية قراءة) — لا بكسلات؛ محاكاة بكسل تتطلب متصفحاً كاملاً غير متوفر في بيئة التطوير هذه (وثّق ذلك في الحكم المقارن).
